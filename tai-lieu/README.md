# Tài liệu Học Toán Vui

| File | Nội dung |
|---|---|
| `Huong-dan-su-dung-Hoc-Toan-Vui.pdf` | Hướng dẫn sử dụng cho ba mẹ (9 trang, có ảnh màn hình) |
| `Gioi-thieu-Hoc-Toan-Vui.pdf` | Giới thiệu app (4 trang) |
| `facebook/` | 4 ảnh vuông 1080×1080 và `noi-dung-bai-dang.txt` (1 bài chính + 2 bài ngắn) |
| `anh/` | Ảnh chụp màn hình app và mã QR mở app |
| `nguon/` | File HTML/CSS nguồn để sửa nội dung rồi in lại PDF/ảnh |

Sửa PDF: mở file `.html` trong `nguon/` bằng Chrome, chỉnh nội dung, rồi bấm Ctrl+P → Lưu dưới dạng PDF (bật "Đồ họa nền").
